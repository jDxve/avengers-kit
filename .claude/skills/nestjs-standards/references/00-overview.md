# NestJS Backend Standards

A reusable engineering standard for building, reviewing, and operating production NestJS
APIs. Project-agnostic. Drop it into any NestJS repo.

**Scope:** this defines *how* to build a backend. It does not define your domain model,
deployment topology, or capacity requirements. Those are per-project and belong in a
separate architecture doc.

**Target architecture:** a modular monolith with enforced boundaries. Start here. Introduce
additional infrastructure when a requirement demands it, not to look sophisticated.
